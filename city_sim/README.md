# AI City Sim (текущий сценарий)

Один эксперимент, оба участника — Claude (я, через вашу подписку Pro, без
API-ключей): **Игорь Соколов**, 35 лет, без опыта в бизнесе, стартует с
100 000 руб бизнес по аренде кладовых боксов ("СкладОК") в Барнауле, начиная
с 27.07.2026, в текущих экономических условиях. И **Городская комиссия
(гос. органы)** — собирательный образ ФНС/пожнадзора/Роспотребнадзора/
администрации, следящий, чтобы всё велось по закону.

**Цель:** дойти до пассивной ежемесячной прибыли от 2 000 000 руб хотя бы
4 недели подряд — за 26 недель (~6 месяцев при темпе 1 неделя = 1 день).
С нуля, без навыков и почти без капитала это очень амбициозно — весь смысл
в том, чтобы посмотреть, к чему реально приведёт последовательность разумных
решений за отведённый срок.

15 других бизнесменов (Gemini/Groq/DeepSeek/Ollama/GitHub Models, 3 персонажа
из предыдущей версии эксперимента) и юрист остались в `agents_config.json`
с `"active": false` — можно включить обратно позже, сейчас в тиках не участвуют.

## Установка

```
cd city_sim
pip install -r requirements.txt
```

Внешние API-ключи сейчас не нужны — оба активных агента (Игорь и гос.
органы) провайдер `"claude"`, их ход поставляю я через `claude_turn.py`,
а не автоматический вызов API.

## Два режима запуска

### 1. Быстрый одноразовый тест (в памяти, без сохранения состояния)

```
python main.py 3
```

Прогоняет 3 недели в одном процессе без сохранения — с активными агентами
(оба на Claude) это просто покажет, что Игорь "держит паузу" каждую неделю,
пока не подключен постоянный конвейер. Пишет в `logs/run_<ts>.jsonl` и
`Рабочий стол/Дневник_ИИ_города/run_<ts>_test_diary.md`.

### 2. Постоянный ежедневный конвейер (реальный эксперимент)

Состояние живёт в `city_sim/state.json` и переживает между запусками, а
`daily_run.py` синхронизирует его через git с
https://github.com/bybit03092003-ui/ai-city-sim, чтобы локальный ПК и
облачный агент видели одно и то же состояние.

- **Локально:** Планировщик заданий Windows → `daily_run.py` раз в день
  (`git pull` → `advance_week.py` → `git commit/push`). Тикает город и (для
  активных не-Claude агентов, сейчас таких нет) опрашивает API.
- **Я (Claude), раз в день, через облачный routine:**
  1. `python claude_turn.py show "Игорь Соколов"` — вижу состояние города и бизнеса
  2. Рассуждаю за Игоря как за новичка без опыта, решаю ОДНО действие на неделю
  3. `python claude_turn.py apply "Игорь Соколов" --action "..." --reasoning "..." --cash_delta N --revenue_change N --cost_change N --notes "..."`
  4. Если в это время на рассмотрении дело от гос. органов (проверка после
     рискованного хода Игоря) — `python claude_turn.py show "Городская комиссия (гос. органы)"`
     покажет факты дела, и я выношу решение:
     `python claude_turn.py apply_regulator "Городская комиссия (гос. органы)" --target "Игорь Соколов" --fine N --verdict "..."`
  5. Коммичу и пушу `pending_*.json` в репозиторий — локальный
     `daily_run.py` подхватит на следующем тике.

Если я где-то пропущу день — соответствующий ход просто не происходит на
этой неделе, ничего не ломается.

## Настройка

Правьте `agents_config.json`:
- `monthly_profit_goal` — целевая пассивная прибыль в месяц (сейчас 2 000 000 руб)
- `profit_stable_weeks_required` — сколько недель подряд нужно держать эту прибыль (сейчас 4)
- `deadline_week` — неделя финального отчёта (сейчас 26 = ~6 месяцев)
- `start_date` — дата начала симуляции в реальном мире (27.07.2026)
- `history_keep` — сколько последних недель истории агент помнит в промпте
- `agents` — персонажи; у каждого `"active": true/false` включает/выключает участие в тике

На неделе `deadline_week` скрипт сравнивает недельную прибыль каждого
активного бизнесмена с целевой (переведённой в недельный эквивалент) и
пишет итоговый отчёт (достигнута цель или нет) в дневник и `state.json`
(`meta.concluded = true`). После этого `advance_week.py` больше ничего не
делает при повторных запусках.

Чтобы начать эксперимент заново — удалите `state.json`, `pending_*.json` и
`Рабочий стол/Дневник_ИИ_города/diary.md`; `advance_week.py` создаст всё
заново при следующем запуске.

## Известные ограничения прототипа

- `economy.py` — упрощённая случайная модель спроса/инфляции, не привязана
  к реальной статистике по Барнаулу.
- И бизнесмен, и регулятор сейчас оба — Claude, ход по расписанию/вручную,
  а не автоматический вызов API; если день пропущен, соответствующий шаг
  просто не происходит на этой неделе.
- Остальные 14 бизнесменов + юрист из предыдущей версии эксперимента лежат
  в конфиге неактивными — для их включения нужны настоящие бесплатные ключи
  (Gemini/Groq/OpenRouter/GitHub) или локальный Ollama.
