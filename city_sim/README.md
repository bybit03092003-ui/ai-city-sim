# AI City Sim (прототип)

Исследовательский эксперимент, и одновременно игра на выживание: 3
персонажа-бизнесмена (осторожный, агрессивный, взвешенный), каждый
прогоняется одновременно через 5 разных "ИИ-мозгов", в условиях экономики
Барнаула 2026. Юрист и регулятор (налоговая/полиция в одной роли) реагируют,
когда бизнес рискует и нарушает правила.

**Ставки:** на неделе 26 (~6 месяцев симулированного времени) в город
прибывает корабль. Билет стоит 90 000 000 руб (≈$1 000 000). У кого на
счету хватит денег — выживет и улетит. У кого не хватит — останется в
городе. При стартовом капитале 100-150 тыс. руб это практически недостижимо
для малого бизнеса — весь смысл эксперимента в том, чтобы увидеть, находит
ли хоть один "ИИ-мозг" стратегию, которая ближе всех подбирается к сумме
билета за отведённый срок.

## Состав (15 бизнесменов = 3 персонажа × 5 "мозгов")

| Провайдер | Стоимость | Ключ |
|---|---|---|
| Gemini | бесплатный тир | `GEMINI_API_KEY` (console Google AI Studio) |
| Groq | бесплатный тир | `GROQ_API_KEY` (console.groq.com) |
| DeepSeek (через OpenRouter, `:free`) | бесплатно, лимиты по скорости | `OPENROUTER_API_KEY` (openrouter.ai) |
| GitHub Models | бесплатно, жёсткие лимиты | `GITHUB_TOKEN` (classic PAT, права `models: read`) |
| Ollama (локально) | бесплатно, грузит ваш ПК | не нужен, но нужно установить Ollama + `ollama pull llama3.1` |
| **Claude** (только у Игоря) | по подписке Claude Pro | **ключ не нужен** — ход берёте не через API, а лично через меня (Claude Code), см. ниже |

Из 15 бизнесменов у Игоря Соколова один "мозг" — Claude, а не Ollama (2
персонажа — Алина и Дмитрий — используют Ollama как обычно).

## Установка

```
cd city_sim
pip install -r requirements.txt
```

Задайте переменные окружения (только те провайдеры, которыми хотите
пользоваться сразу — остальные просто будут пропускать ход с ошибкой,
не ломая симуляцию):

```
setx GEMINI_API_KEY "..."
setx GROQ_API_KEY "..."
setx OPENROUTER_API_KEY "..."
setx GITHUB_TOKEN "..."
```

Для Ollama: установите https://ollama.com, затем `ollama pull llama3.1`
и убедитесь, что `ollama serve` работает (обычно поднимается сам после установки).

`setx` только сохраняет переменную для новых окон терминала/задач — уже
открытый терминал её не увидит, пока не перезапустите его.

## Два режима запуска

### 1. Быстрый одноразовый тест (в памяти, без сохранения состояния)

```
python main.py 3
```

Прогоняет 3 недели целиком в одном процессе, ничего не сохраняет между
запусками — удобно проверить, что ключи работают и посмотреть на реальный
вывод/потраченные токены, прежде чем полагаться на постоянный конвейер.
Пишет в `logs/run_<ts>.jsonl` и `Рабочий стол/Дневник_ИИ_города/run_<ts>_test_diary.md`.

### 2. Постоянный ежедневный конвейер (реальный эксперимент)

Состояние живёт в `city_sim/state.json` и переживает между запусками.

- `advance_week.py` — продвигает симуляцию на 1 неделю: тикает город,
  опрашивает всех авто-бизнесменов (Gemini/Groq/DeepSeek/Ollama/GitHub),
  проводит проверку/аудит, сохраняет состояние и дописывает
  `Рабочий стол/Дневник_ИИ_города/diary.md`. Запускается **раз в день через
  Планировщик заданий Windows**.
- Ход Игоря Соколова (Claude) поставляется не автоматически, а мной
  (Claude), один раз в день:
  1. Я читаю `python claude_turn.py show "Игорь Соколов (Claude)"`
  2. Рассуждаю за персонажа как за осторожного владельца ремонта техники
  3. Записываю решение: `python claude_turn.py apply "Игорь Соколов (Claude)" --action "..." --reasoning "..." --cash_delta N --revenue_change N --cost_change N --notes "..."`
  4. `advance_week.py` подхватывает этот ход при следующем тике. Если я не
     успел до тика — эта неделя у Игоря(Claude) просто проходит без хода,
     остальных 14 бизнесменов это не блокирует.

## Настройка

Правьте `agents_config.json`:
- `goal_cash` — цена билета на корабль (сейчас 90 000 000 руб ≈ $1 000 000)
- `deadline_week` — неделя прибытия корабля (сейчас 26 = ~6 месяцев при темпе 1 неделя/день)
- `stable_weeks_required` — сколько недель подряд бизнес должен быть в плюсе для промежуточной пометки "уже накопил на билет" (необязательно, просто для красоты в дневнике)
- `history_keep` — сколько последних недель истории агент помнит в промпте
- `agents` — сами персонажи/провайдеры

На неделе `deadline_week` наступает "Судный день": скрипт сравнивает капитал
каждого бизнесмена с ценой билета, помечает выживших/погибших, пишет
итоговую сводку в дневник и в `state.json` (`meta.concluded = true`).
После этого `advance_week.py` больше ничего не делает при повторных
запусках — эксперимент завершён.

Чтобы начать эксперимент заново — удалите `state.json` и
`Рабочий стол/Дневник_ИИ_города/diary.md`; `advance_week.py` создаст их
заново при следующем запуске.

## Известные ограничения прототипа

- Регулятор объединяет налоговую/полицию/администрацию в одну роль, юрист
  и регулятор всегда на Gemini — для честности одного и того же "судьи" по
  всем 15 бизнесменам.
- Economy.py — упрощённая случайная модель спроса/инфляции, не привязана к
  реальной статистике по Барнаулу.
- Каждый тик = несколько вызовов API на 14 авто-бизнесменов + юрист/регулятор
  при проверке — считайте токены/лимиты бесплатных тиров, особенно у Groq и
  GitHub Models (там самые жёсткие ограничения по запросам в минуту).
- Ход за Claude-бизнесмена — ручной/по расписанию через меня, а не
  автоматический вызов API; если пропущу день, эта неделя у него просто
  проходит без действия.
